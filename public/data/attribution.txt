Worldpick city dataset
======================
Source: GeoNames cities1000 (https://www.geonames.org/)
GeoNames data license: Creative Commons Attribution 4.0 (CC BY 4.0)
https://creativecommons.org/licenses/by/4.0/

Redistribution: all-the-cities@3.1.0 by Zeke Sikelianos
https://github.com/zeke/all-the-cities
Derived from cities-with-1000 by Nabil Ashraf.

This project includes the complete 135,233-record snapshot from that release,
reformatted to [geonameId, name, countryCode, longitude, latitude]. Other
fields were removed. Place names, country codes and coordinates are retained.
The package description says 138,398; the actual release contains 135,233
unique GeoNames IDs. This is a historical cities1000 snapshot, not the latest
GeoNames release or a list of every settlement on Earth.
